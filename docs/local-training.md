# 物料计数与本地训练

设置弹层中的 **物料计数 / 模型管理 / 训练中心** 共用设备数据。首页只显示当前两区数量、会话累计与待核对提醒。中英文切换不会清除标注、区域草稿或训练任务。

## 安装与运行

继续使用项目原来的 `./start.sh`。第一次部署训练功能时执行：

```bash
cd /home/seeed/workspace/jetson-worktime
./scripts/install_training_service.sh
sudo loginctl enable-linger seeed
systemctl --user status worktime-training.service
./start.sh
```

训练监督进程独立于网页服务。关闭浏览器或重启网页不会终止训练。设备重启后任务显示“中断待恢复”，不自动抢占生产 GPU；在训练中心手动恢复。停止最多等待30秒，之后保留最近完整 epoch 的检查点。当前未完成批次不会恢复。

## 先使用已有模型

1. 打开模型管理，上传可信的 YOLO11 Detect `.pt`，或兼容 COCO 17关键点的 YOLO11 Pose `.pt`。
2. 人员模型和物料模型分别选择。上传只进行独立CPU兼容检查，不自动启用。
3. 选择物料模型中的产品类别，点击启用。GPU暖机失败恢复原模型，并关闭物料计数等待重新确认。
4. 到物料计数获取参考画面，画出互不相交的待完成区和完成区，调整颜色、透明度和显示开关，保存。

官方预训练权重是训练起点，不等于已经能检测工厂里的自定义产品。未提供专用权重时，物料计数默认关闭、物料模型为空。原人员模型和原设备参数保持不变。

## 采集、标注与划分

- 每个项目支持多个类别。在标注页输入类别名称并添加，先选类别再画框；选中框后可更换类别。类别用不同颜色和文字区分。已被标注或快照引用的类别不能删除，旧项目的原类别自动作为类别0。训练快照冻结类别列表，后续重命名不改历史快照。
- 先选择或创建项目，点击“打开摄像头”查看实时画面，再点击“拍照”或“开始连续采集”（默认间隔2秒，从上一张保存完成后计算）。显示本次新增数、项目总图片数和最近样本；重复图片去重后不重复增加数量。
- 点击“完成采集，进入标注”，系统停止连续采集、等待最后一张保存完成并释放实时连接，再显示标注画布。需要补拍时点击“继续采集”。采集阶段不会自动进入标注。
- 断流或算法不可用时停止连续采集。页面隐藏、切换工作区或关闭设置也会释放预览；返回后手动打开。预览使用无区域、无检测框和无骨架的独立视频流，保留隐私处理；localhost和局域网使用高清（最高1920宽/12FPS/4Mbps），仅Tailscale地址（100.64.0.0/10或*.ts.net）使用640宽/10FPS/600Kbps流畅档，保存样本保持完整原分辨率且不烧录检测标注。切换摄像头仍使用原有测试与区域确认流程。
- 摆放或背景改变后点击“新采集组”。至少准备3个独立且含有正样本的组，分别用于训练、验证和测试。不要把相邻帧当作独立验证素材。
- 保存完整画面，遵循当时设备隐私设置，不烧录检测图层。上传图片也经过同样隐私策略。标注产品时避免使用被隐私蒙版遮住的目标作为有效样本。
- 图片支持JPEG/PNG，单张不超过20 MB / 2400万像素。权重不超过512 MB。原始文件名不作为磁盘路径。
- 框出每个产品，点击框可移动、角点可缩放；删除、撤销及无目标确认均可用。修改自动保存，冲突不会覆盖其他浏览器的版本。
- 默认80/10/10，拖动或输入百分比。按完整采集组分配，实际图片比例会偏离目标比例，以快照显示的数量为准。
- 快照冻结图片、标签、类别和分组。后续修改标注或软删除图片不会改变旧快照。

## 本地训练与投用

先选择并下载官方YOLO11n / m / l。固定来源和SHA-256记录在 `configs/model-catalog.json`。下载失败可重试，校验失败不进入模型库。

默认100轮、学习率0.001、AdamW、640尺寸、n的Batch为4，m/l为1。更大模型不一定适合当前资源；预检失败不会偷偷缩小Batch或切为CPU。修改参数创建新任务；恢复训练继续使用原快照与参数。学习率按预热及训练进度变化，界面显示实际值；AdamW的偏置预热从0开始，不沿用SGD的0.1偏置预热值。

开始训练会结算当前会话，释放业务模型和GPU，暂停业务直播。进度包括真实epoch、损失、验证指标、实际学习率和估算剩余时间。验证集用于训练选择，测试集在训练结束后独立评价。保存产物完成后才显示成功。

训练完成后查看独立测试指标和现场预览，再手动投用。新模型不自动替换生产模型。模型准确性取决于实际样本和标注，训练完成不等于通过产品计数验收。

## 计数口径

- 产品框中心落在哪个区域，就属于哪个区域；在位区与物料区没有包含关系。
- 默认稳定进入1秒、漏检缓冲2秒、检测2Hz、产品置信度0.25。
- 新会话第一份稳定观察中，完成区已有5件则会话累计从5开始。上次会话留下的成品仍会重新计入新会话。
- 新件进入完成区稳定后累计加一，取走不扣减；短时遮挡和连续身份内的放回不重复计。
- 失去身份的回流候选需要核对：选新件加一，旧件不增加。累计支持填写原因后人工修正；所有修改保留记录，请求重试不重复执行。
- 断流、过期、区域待确认、训练期间显示不可用，不把未知伪装为零。

## 数据与恢复

`data/worktime.sqlite` 为SQLite元数据库，启用WAL与完整同步。`data/models` 保存权重，`data/datasets` 保存图片与不可变快照，`data/training` 保存日志、结果及两代恢复检查点。上述目录已被Git忽略，不会随代码上传。

备份数据库时使用SQLite在线备份接口，不能仅复制正在写入的sqlite主文件。备份图片、模型和快照时保留相对目录。模型及快照编号、校验值、会话号和帧序号在事件中可查。

回退代码前停止当前训练并确认子进程退出，再停止训练监督服务和网页服务，恢复部署前代码备份。保留整个 `data/`、设备 `.env` 与设备配置；不要用仓库示例配置覆盖工厂现场配置。
