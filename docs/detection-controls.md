# 检测启停、清零与首页计数

首页保留大工时计时器、状态 Pipeline，以及装配区／成品区两张实时计数卡片。区域卡片只显示配置中统计标签的当前总件数；1 个盒子加 1 块电路板显示 2，不换算为套数。成品区只显示合格完成数，异常标签不计入。检测关闭、断线或观测过期时显示“—”，不显示为正常零数量。

- **检测开关**：关闭后结算当前会话并保存历史，停止工时与物料业务检测，显示无标注实时画面。隐私开启时仍执行打码所需的人员检测。重新开启后从新画面重新确认开工，不补计调试时间。设备重启后保持已保存的开关状态。
- **清零时间**：确认后清零当前主页时长与开工确认，结算当前会话并保留历史工时、产量、告警和人工调整。关闭检测时清零不会重新开启检测。
- **置信度显示**：设置 → 装配计数 → 显示物料置信度 → 保存并应用。只控制分数文字，不改变识别阈值、数量或会话。
- **详细记录**：会话统计中可查看工作、休息、待确认、未知时长及初始成品、新增完成和累计量。待核对与人工调整继续在设置 → 装配计数中处理。连接指标收纳到会话统计的“连接详情”。首页不显示重复诊断文字、操作员说明、配置版本或性能面板。

成品区稳定发现异常标签时，数量卡下方出现“未达标打包件”红卡；未发现异常、异常解除或检测不可用时隐藏。默认稳定确认 1 秒、短时漏检缓冲 2 秒。

新设备默认开启检测和置信度显示。页面与设置同步支持中文和英文。工位区域采用低对比灰蓝细线与浅蒙版；物料区域采用琥珀／蓝色，区域位置仍按现场配置，不会自动移动。

本设备装配区统计标签为 box、part，成品区合格标签为 packed，异常标签为 not_packed。更换模型后仍通过设置选择各区域的统计与异常标签，首页总数不按名称猜测。不要将同一标签同时配置为统计与异常。

前端 Mock 可用 `/mock/scenario?name=assembly`、`assembly_alert`、`assembly_stale` 验证正常2/2、异常红卡与观察失效，不会写入生产数据。

工位范围使用共享的纵向渐变与边缘羽化蒙版，直播、截图和对应帧均不再绘制工位外围虚线。工位颜色保持设备已保存的选择，station_fill_alpha 表示渐变峰值透明度；关闭工位显示可隐藏整个图层。ROI 编辑时保留清晰的边界和顶点，编辑操作不改变判定几何。物料区和在位区的独立样式不变。
