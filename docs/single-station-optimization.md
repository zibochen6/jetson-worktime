# 单工位优化交付与接入验收

本版先完成后端、单路展示和离线验证。用户决定稍后接入摄像头，现场准确率、实际操作时长误差、浏览器播放帧率和长时间运行结果需届时测量。

## 数据与模型

原始 VOC 数据保持不变：103 张图片、725 个实例，四个类别为 box / not_packed / packed / part。按画面内拍摄时间的整分钟分组，64 张训练、20 张验证、19 张测试；同一原图的衍生裁剪均留在相同组。裁剪方案另外加入 20 张来自训练组的背景裁剪。全画面基线不含这 20 张背景，因此此处比较的是整体优化方案，并非单独裁剪的消融实验。

来源是同一机位的一个短时间段，相邻分钟仍可能相似，不能代表跨机位、跨工厂泛化。冻结测试组有 38 个 packed、54 个 box、57 个 part，没有 not_packed；未完成品在测试组上的效果尚未验证。验证组包含全部四类。原图、分组、时间识别修正和裁剪坐标记录在 `dataset-v2/manifest.json` 中。

验证集模型选择：全画面 mAP50 为 0.87854、mAP50–95 为 0.49983；裁剪方案分别为 0.93012、0.51480。按验证集 mAP50–95 选择裁剪模型，测试集随后只做一次模型评估。测试集三个已出现类别的 mAP50 为 0.98114、mAP50–95 为 0.55818。上述均为图像检测指标，不等同于完成计数准确率。

类别门槛由验证集 F0.5 扫描确定，优先精确率：box 0.55、not_packed 0.20、packed 0.20、part 0.60；全局最低门槛 0.20。更高的零件门槛会降低召回率，需要在实际连续视频中验收。测试分数不参与这些门槛的选择。

## 行为变化

- 物料推理使用装配区与成品区的联合工作台裁剪，结果还原到原画面坐标；尺寸或区域不匹配时回退到全画面输入。
- 新会话的“本次完成”排除初始库存。观察到装配区来源、稳定进入成品区才自动增加；身份不明、缺少过程、取走后返回进入复核。
- 完成与复核事件持久保存对应的受隐私策略处理的检测帧。页面标出对应物品，可手工确认；重复提交不重复计数。旧历史保留原定义。
- “在岗时间”保留旧规则。“操作时长估算”另行统计，结合操作员手腕、局部运动及物料邻近关系；缺少证据、遮挡、观测间断记未知。该估算仍需现场校准。
- 人体与小物料分开跟随显示；跟随结果只用于画面，不参与计数或隐私处理。过期框继续隐藏。
- 视频先缩放到播放尺寸再绘制；证据写盘使用有界队列，避免阻塞推理。加速缓存绑定权重、硬件及 TensorRT 版本，异常时保留 PT 回退。

## 加速一致性

两个模型均在当前 Jetson 上生成静态 FP16 TensorRT 引擎，保持原 PT 权重作为回退。仅使用验证组进行加速一致性检查：物料 142 个框全部匹配、无额外框；人体 20 个框全部匹配，关键点误差的 95 分位为画面宽度的 0.098%。框匹配要求同类别且 IoU ≥0.8。

物料模型单独运行时，推理中位耗时由 41.7 ms 降至 23.4 ms；姿态模型由 44.4 ms 降至 23.3 ms。这是独立模型耗时，不能相加后直接推断整机帧率。缓存清单同时记录权重、引擎哈希、硬件与 TensorRT 版本；不匹配时不使用缓存。

## 后端实测与测试

在 Jetson 上用同一张 2560×1440 验证图、20 FPS 重复输入，运行真实检测、计数、跟随显示、证据和 1080p 编码工作线程。两个版本分别预热至自动进入会话、库存初始化完成，再测量 60 秒；不含摄像头解码或浏览器呈现，隐私开关沿用现场的关闭状态。下表按整个测量区间的次数除以实际时长计算，并非取最后数秒的瞬时速率。

| 指标 | 原部署代码与旧模型 | 本版代码与新模型 |
| --- | ---: | ---: |
| 物料检测更新 | 5.33 次/秒 | 7.48 次/秒 |
| 1080p 编码提交 | 16.94 帧/秒 | 18.13 帧/秒 |
| 初始库存 | 2 | 2 |
| 静置额外完成事件 | 0 | 0 |
| 检测、证据写入、视频工作线程错误 | 0 | 0 |

物料更新约提升 40%，但仍未达到 8 Hz 的目标。编码提交达到 18 FPS，不代表现场浏览器播放已经验收。最终测量内主进程内存约 1354→1355 MiB，60 秒不足以判断长期稳定性。最终报告为 `benchmark-final/report.json`，早期调优结果另存，未覆盖。

最终代码在 Jetson 上通过全部 250 项后端测试；本地通过全部 62 项前端测试。覆盖旧历史兼容、初始库存排除、完成计数与复核幂等、未知时段、框跟随失效、证据和隐私边界、加速缓存校验及视频工作线程。桌面与手机页面完成布局检查，线上摄像头离线时显示未知和无数据。

## 摄像头接入后的验收

1. 在设置中测试摄像头连接，确认 2560×1440 原图，并重新检查人员区、装配区、成品区。训练图与部署前现场的物料位置不同，不能照搬旧区域坐标。
2. 放置已有成品后开始会话：初始库存正确，“本次完成”为 0；静置 60 秒，额外完成应为 0。
3. 完成至少 30 个动作，包含正常装配、短暂遮挡、未完成品、取走后放回。逐条核对事件证据：误加目标 0、漏计目标不超过 1、自动计数加可复核覆盖率目标至少 90%。
4. 人工标记至少 10 分钟实际操作、停手、离位和遮挡片段，比较操作时长估算；误差目标 ≤5%、未知占比目标 ≤10%。不达标时继续标为估算，不用于正式工时结算。
5. 实际播放 1080p 单路，分别查看采集、编码、浏览器播放与物料观察。目标：浏览器 ≥18 FPS、物料 ≥8 Hz；连续 30 分钟不积压，内存不持续增长。
6. 通过后录制新的单路演示。多路、真实功耗、摊到每路的设备成本尚未验收，本版不作多路能力承诺。
