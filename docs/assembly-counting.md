# 装配计数

打开 8088 首页的设置 → 装配计数。

1. 选择物料模型 `detect_pack_yolo11n_20261112`。它是本次训练的四类别模型，已注册，默认没有启用。
2. 获取当前摄像头参考画面，用矩形或多边形圈出待装配区和成品区。两个区域不得重叠；画面、相机或分辨率变化后须重新确认，勿直接使用其他机位的示意区域。
3. 待装配区：box 与 part 设为“统计数量”，其余“不参与”。成品区：packed 设为“统计数量”，not_packed 设为“异常提醒”。
4. 可展开类别显示名称／颜色，将 not_packed 的显示名改为“未打包完成”。每区可改名、调颜色和透明度，独立开关区域或填充蒙版；隐藏不影响计数。
5. 勾选启用并保存。修改模型、标签规则或区域会结算当前会话并重新确认开工；纯显示修改不会结算。

每个框按中心点确定区域，连续稳定确认后进入数量。默认置信度0.25、稳定1秒、漏检缓冲2秒；人员和物料对每个实际处理的新帧持续推理，数量经过多帧投票确认。输入区的盒子和电路板分别统计，不推断套数。成品区的异常目标不计合格成品；目标稳定变为正常或离开时解除提醒。支持的异常标签由用户选择，本功能不保证识别未训练的缺陷。

会话首次稳定观察的合格成品计入初始量，之后新增项计入新增量，累计包含两者及人工调整。成品移走不扣累计。已计数物体变为异常时，累计先保留并进入人工核对，可填写原因扣减或保留。长期离开后无法确认身份的同类回流候选会要求核对；相同外观无法永久辨认个体，频繁清空成品区时可能需要人工核对。不要将框数当成跨场景准确性保证。

累计绑定工时会话；若人员工位范围和在位判断区尚未确认，请先在场景设置确认它们。无活动工时会话时，显示当前数量和提醒，不累计产量。数量为“—”表示观测、区域或模型暂不可用，不表示0。首页的累计仍是会话历史值。告警记录支持当前及已解除事件；历史记录保留当时的模型和类别解释。

物料标注共用设备媒体处理，直播、截图及对应帧使用同一套配色和标签。已取消物料每秒2次的限频。每个实际进入算法的新帧先检测人员、再检测物料，结果进入计数稳定窗口；原始视频不等待两个模型逐帧处理。模型处理落后时只保留最新输入，实际推理频率由负载决定。直播在结果完成后最多允许300毫秒的运动跟随，来源帧总年龄不超过750毫秒，失配或过期立即隐藏；跟随不参与计数或隐私。设置中保留置信度、稳定时间和漏检缓冲，不再显示检测限频。旧 sample_hz 字段仅作计数窗口兼容参考，不会限制模型速度。

新模型不按字符串自动配置用途。重新选择模型会清空标签规则并关闭装配计数，确认类别映射后再启用；同一区域的一个类别只能选统计或提醒之一。旧配置仍按原单类别迁移。
