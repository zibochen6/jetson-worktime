# 工时统计系统 V4 前端

V4 使用深色工业控制台布局，突出 reComputer Industrial 产品、真实直播、当前状态和会话工时。Standard 保留全部操作，Showcase 隐藏低频管理入口，两种模式共用数据和组件。语言与展示模式按浏览器保存。

设置在首页弹层中打开，复用 `/settings?embedded=1` 编辑器。工位配置入口直接定位 ROI。关闭弹层与切换中英文保留未保存草稿及撤销记录。保存仍需用户点击“保存并应用”，设备设置由所有观看者共享。

## 运行与验证

需要 Node.js 20+，没有第三方前端运行依赖。

- `npm run mock` 启动明确标记的合成画面联调服务。
- `API_BASE_URL=http://192.168.2.16:8088 npm run dev` 代理真实设备。
- 默认访问 `http://127.0.0.1:5173`，使用 `PORT` 可以修改端口。
- `npm test` 执行前端测试。
- 在项目根目录执行 `node scripts/verify_v4_ui.mjs http://192.168.2.16:8088`，只读检查实际首页、全部检查项中的静态资源与源文件一致，以及配置状态。

## 代码职责

- `public/index.html` 是设备与开发服务器共同使用的首页，包含导航、直播、状态卡片、Pipeline、底部面板及弹层。两张压缩产品 WebP 嵌入其中，适配设备静态文件白名单。
- `public/main.css` 管理深色设计变量、响应式布局及展示模式。`public/main.js` 管理接口轮询、交互、模式和数据呈现。
- `public/api.js` 提供接口辅助和纯展示映射 `dashboardView`。状态转换仍由 `pipeline.js` 映射，所有计时由后端结算。
- `public/settings.html/settings.js/settings.css` 及 `roi-editor.js` 复用现有设置与区域编辑能力。
- `public/i18n.js/locales.json` 管理中文、英文及现有服务提供的标注语言。静态文本不重复替换文字节点，减少轮询带来的无效重绘。

## 数据口径

统计为当前会话或最近结束会话，不表示每日总量。工作、休息、待确认、未知四类时长合计作为占比分母，数据缺失或合计为零时占比显示“—”。短暂离开确认期内返回会补计工时，现有规则不变。

顶部从 `/api/v1/system/metrics` 读取设备 GPU、CPU、已用／总内存和芯片最高温度，约每两秒刷新；读失败的指标显示“—”。运行信息使用 `output_fps`、`local_processing_ms`、`age_ms`，分别表示输出帧率、本地处理耗时和观测年龄。过期、不同配置或不同相机会话的观测会被过滤。

时间轴尚无历史分段接口，显示空状态。不会用累计值推算历史色带。

## 媒体与设置

继续使用现有 MJPEG 直播和受保护截图，优先保证流畅度。检测标注沿用服务端现有样式，后续媒体层统一青绿色角框。头部打码、检测图层和双语标注继续遵循后端配置。

区域使用原图像素坐标，支持矩形、多边形、顶点拖动、撤销与触摸。保存 ROI 需要有效截图及其来源会话和分辨率。ROI 或时长改变会结束活动会话，按新规则重新确认开工。隐私和图层单独更新。

Mock 在内存中模拟全局配置、版本冲突、首次配置和十种情景。真实设备的配置写入与人工操作会改变现场记录，回归时应在 Mock 验证写入行为，现场验证采用只读操作。

产品源素材存于 `assets/`。更新后运行项目根目录的 `node scripts/embed_product_images.mjs`，重新嵌入首页。`scripts/check_v4_layout.mjs` 导出浏览器布局验证函数，接收现有 ego-browser Page，返回24组检查记录。

## 检测标注样式

`public/overlay-style.json` 统一定义后端视频、前端 Canvas、ROI 编辑器和图例使用的配色、尺寸、骨架连线及新设备默认开关。设备静态白名单同时提供此文件和 `overlay.js`。已有配置中的显示开关按保存值加载，新设备默认关闭关键点。

带标注直播由当前帧的检测结果生成，隐私保护先于标注。原图像素坐标及观测 ID 继续作为几何与图像匹配依据。前端对应帧可通过 `drawResult(canvas, image, observation, {fresh: envelope.fresh, regionsMatch: camera.regions_match})` 绘制，调用前需校验版本和流会话。过期帧停止输出，页面恢复连接后重新取流。

头脸保护使用粗颗粒像素马赛克，保护区域内部完全像素化，柔化过渡仅延伸至区域外侧。根据脸部关键点及肩部参考扩大头部范围，定位不足时覆盖整个人体。检测结果不可用时沿用整帧遮挡或暂不可用输出。统一媒体出口覆盖直播、截图、对应帧及新增保存素材。
